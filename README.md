# 🛒 Supermarket Sales Analytics

### Retail Performance Dashboard Using Tableau

A data analytics project that transforms supermarket transaction data into meaningful business insights through an interactive Tableau dashboard.

## 📌 Project Overview

This project analyzes supermarket sales data from three cities in Myanmar: Yangon, Mandalay, and Naypyitaw.

Using Tableau, the project explores sales performance, revenue trends, customer payment preferences, and customer satisfaction to help understand retail business performance.

## 🎯 Objectives

- Explore and analyze supermarket sales data.
- Examine data quality, missing values, and duplicate records.
- Calculate key performance indicators (KPIs).
- Visualize monthly revenue trends.
- Compare sales revenue across cities.
- Analyze customer payment preferences.
- Compare customer ratings across product lines.
- Present the findings through a consolidated Tableau dashboard.

## 🛠️ Tools and Technologies

- **Tableau Public Desktop** — Data visualization and dashboard development.
- **CSV** — Dataset storage and input.
- **GitHub** — Project version control and hosting.

## 📊 Dataset

**Source:** [Supermarket Sales Dataset — Kaggle](https://www.kaggle.com/datasets/aungpyaeap/supermarket-sales)

The dataset contains 1,000 transactions and 17 attributes, covering three supermarket branches between January and March 2019.

Key attributes include:

- Invoice ID
- Branch and City
- Customer Type
- Product Line
- Unit Cost
- Quantity
- Revenue
- Date and Time
- Payment Method
- Gross Income
- Customer Rating

## 📈 Dashboard Features

The dashboard combines four KPI cards with four visualizations.

### Key Performance Indicators

- **Total Transactions:** 1,000
- **Total Revenue:** 322,966.75
- **Units Sold:** 5,510
- **Average Customer Rating:** 6.973/10

### Visualizations

1. **Monthly Revenue Trends:** Compares sales revenue across January, February, and March 2019.
2. **Sales by City:** Compares revenue generated by Yangon, Mandalay, and Naypyitaw.
3. **Payment Distribution:** Examines the use of cash, credit cards, and e-wallets.
4. **Customer Ratings:** Examines customer satisfaction across product lines.

## 🔍 Key Findings

- January recorded the highest monthly revenue.
- Naypyitaw generated the highest revenue among the three cities.
- E-wallets were the most frequently used payment method.
- Customer ratings were relatively similar across product lines.
- The dataset contained no missing values or duplicate records.

1. Clone or download this repository.

3. If necessary, reconnect the workbook to the dataset in the `data/` folder.
4. Open the dashboard and explore the visualizations.
5. Refer to the `screenshots/` folder for a preview of the dashboard.
